# ⚡ DEV_PANPAN // NEOBRUTALIST PORTFOLIO & TERMINAL 🚀

A modern, high-voltage **Cyber-Neobrutalist Developer Portfolio** featuring an **Interactive CLI Terminal**, built with **Next.js 14 (App Router)**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Highlights & Features

- 👾 **Interactive CLI Terminal**:
  - Live Shell with executable commands: `help`, `neofetch`, `skills`, `projects`, `stats`, `matrix`, `about`, `contact`, `sudo`, `clear`.
  - **Neofetch View**: Hardware specs, OS telemetry, and dev vitals.
  - **Matrix Rain View**: Live 60FPS HTML5 digital rain canvas animation.
  - One-click quick execute chips & command history navigation (`Arrow Up / Down`).
- 🎨 **Neobrutalism Aesthetic**:
  - Chunky hard drop-shadows (`4px 4px #000`, `6px 6px #000`, neon glows).
  - High-contrast color palette: Electric Cyan (`#00F0FF`), Acid Lime (`#A3E635`), Hot Pink (`#FF2A85`), Cyberpunk Yellow (`#FFE600`).
  - Tactile physical button animations (`btn-brutal`).
  - Scanlines, dot grid backgrounds, and caution ticker banners.
- ⚡ **Full-Stack Architecture**:
  - Next.js 14 App Router, TypeScript strict mode, responsive mobile drawer.
- 🚀 **1-Click Vercel Deploy Ready**:
  - Zero-config deployment with `vercel.json` included.

## 🚀 Quick Start (Local Run)

```bash
# 1. Masuk ke direktori
cd dev-panpan-portfolio

# 2. Install dependencies
npm install

# 3. Jalankan development server
npm run dev
```

Buka **http://localhost:3000** di browser Anda.

---

## 🌐 Deploy to Vercel

1. Push perubahan ke repository GitHub:
   ```bash
   git add .
   git commit -m "feat: neobrutalism design & interactive terminal"
   git push origin main
   ```
2. Buka [Vercel](https://vercel.com/new) dan import repository **`dev-panpan-portfolio`**.
3. Klik **Deploy** — selesai dalam 1 menit! 🎉
